# Archmage Idle — Live Build

**▶ Play now: <https://danielzaiser91.github.io/archmage-idle-live/>**

Medieval-fantasy anime-isekai incremental game: a mage's orb, four elements that feed
each other, elemental spirits with type matchups, and a time layer that resets
everything in exchange for something permanent.

This repository contains **only the built, minified bundle**. It is published
automatically from a private source repository on every release — the branch is
force-pushed, so only the latest build ever lives here. Source code, balance data and
design docs stay private.

- Current version: see [version.json](version.json)
